# VLC Media Player Skin (2.2x HiDPI / Enlarged)

A modified **Windows Media Player** skin (`MediaPlayer_Restored.vlt`) for **VLC Media Player** with enlarged fonts and UI scaling designed for modern high-resolution Windows 11 displays.

## Installation
1. Click **`MediaPlayer_Restored.vlt`** above and click the **Download raw file** button.
2. Open **VLC Media Player**.
3. Go to **Tools** > **Preferences** (or press `Ctrl + P`).
4. Under the **Interface** tab, select **Use custom skin**.
5. Click **Choose...** and select **`MediaPlayer_Restored.vlt`**.
6. Click **Save**, then close and reopen VLC.
